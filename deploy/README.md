# Запуск «Тренер 24» на своём сервере

Что получится: на одном сервере в России работают сайт (тарифы, оферта, политика), мини-приложение, бот и база пользователей. Vercel остаётся только посредником к ИИ и получает запросы без имени и Telegram ID.

## 1. Купить
- Домен, например `trener24app.ru`.
- Сервер: Ubuntu 24.04, 2 ядра, 2 ГБ памяти, 40 ГБ диска.

## 2. Направить домен на сервер
В настройках DNS домена добавить две записи типа A, `@` и `www`, обе на IP сервера. Обычно начинает работать через 15–60 минут.

## 3. Установить
Открыть консоль сервера (в панели хостинга) и выполнить:

```
curl -fsSL https://raw.githubusercontent.com/tima9753-cpu/trener24/main/deploy/setup.sh | bash
```

Скрипт спросит:
- домен;
- почту для SSL;
- токен бота. Токен вводится скрыто, хранится только на сервере в `/opt/trener24/server/.env`.

Установка занимает около 5 минут.

## 4. Проверить и переключить бота
- `https://ДОМЕН/` — сайт
- `https://ДОМЕН/app/` — приложение
- `https://ДОМЕН/health` — должно ответить `{"ok":true,...}`

Если всё открывается, переключить бота на новый сервер:

```
curl -s "https://ДОМЕН/api/bot?setup=1"
```

После этого кнопка «Открыть» в боте ведёт на новый сервер. Данные пользователей при первом входе сами переносятся из Telegram на сервер.

## Дальше
- Обновить код: `bash /opt/trener24/deploy/update.sh`
- Резервные копии базы: каждый день в `/var/backups/trener24`, хранятся 14 дней.
- Логи: `journalctl -u trener24 -f`
